01 — The pipeline

Eight steps.
Zero vibes.

Every prediction is built from documents you actually handed over, then scored by a fixed formula — not by a model's mood.

01

Upload

PDF, DOCX, PPTX, TXT. Scanned pages and phone photos route through Gemini vision automatically.

02

Classify

Each file is tagged: syllabus, past paper, teacher priority, notes or pattern. You can override any label.

03

Analyse

Three analysts extract units, per-topic question frequency, repeats, and what the teacher kept stressing.

04

Score

40% teacher · 25% frequency · 15% syllabus weight · 10% recency · 10% question-type fit.

05

Predict

Topics get a likelihood, a label (must / should / optional) and the exact evidence behind the number.

06

Generate

Mock paper, question bank, model answers, flashcards, formula sheet and a day-by-day plan.

07

Examine

A second model audits the paper for marks totals, difficulty split and syllabus drift — up to two retries.

08

Export

Priority list and mock paper as PDF, a full HTML dashboard, or straight into Google Sheets.

📝

📚

Unit-wise must / should / optional questions with sources tagged back to real papers.

03 — The stack

Three models.
Three free keys.

Orchestrated with LangGraph, served with Streamlit, exported with ReportLab and Jinja2. Nothing on this list bills you.

Primary analyst

Gemini

Reads documents, handles vision on scanned papers, and does the heavy structured extraction.

Get a free key ↗
Examiner / QA

Groq

A different model checks the generated paper so mistakes don't come from the same brain twice.

Get a free key ↗
Fallback (optional)

OpenRouter

When Gemini's free quota runs dry mid-run, requests fail over to a :free model.

Get a free key ↗
RAM friendly Built for an 8 GB laptop — files are processed one at a time, never all at once in memory.
04 — Get going

Up in four
commands.

Clone, install, drop your keys in .env, open the app. Works on Streamlit Cloud or Hugging Face Spaces too.

bash — exam-intelligence 
# 1. clone it
git clone https://github.com/AbhishekAmarvalli/StudSem.git
cd StudSem

# 2. environment
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. keys
cp .env.example .env        # then paste your free keys

# 4. go
streamlit run app.py
  • 1Grab a free Gemini key — it does the reading and the structured extraction.
  • 2Grab a free Groq key — it audits every generated paper before you see it.
  • 3OpenRouter is optional; add it and quota errors stop being your problem.
  • 4Everything stays local. Cached text lives in data/cache and is safe to delete.
